# Midnight Genesis

DIREÇÃO VISUAL — BLACK LUXURY / CINEMATIC

Quero que o visual inteiro seja baseado em um preto extremamente escuro, sofisticado e profundo, com aparência de produto premium.

O fundo principal deve ser quase preto absoluto:

#020202 / #030303 / #050505

Não usar cinza como cor dominante.

O preto deve parecer profundo e tridimensional, não simplesmente uma tela preta.

ILUMINAÇÃO

Criar iluminação cinematográfica extremamente sutil:

Brilhos azul elétrico aparecendo somente em pontos estratégicos.

Gradientes radiais quase imperceptíveis atrás dos elementos.

Reflexos azulados nas bordas.

Glow suave, nunca exagerado.

Pequenos reflexos de luz atravessando a tela durante o scroll.

Partículas muito pequenas flutuando no ambiente.

Efeito de luz volumétrica extremamente discreto.

Áreas completamente pretas contrastando com áreas iluminadas.

A sensação deve ser de uma sala escura iluminada por tecnologia de última geração.

AZUL

Usar azul como luz, não como preenchimento.

Cor principal:

#005BFF

Azul de brilho:

#1677FF

Azul profundo:

#003C99

O azul deve aparecer como se estivesse emitindo luz dentro do preto.

Evitar transformar o site em "site azul".

A proporção visual deve ser aproximadamente:

90% preto
8% branco
2% azul luminoso

EFEITO GLASS / REFLEXO

Quando houver elementos de interface, eles não devem parecer cards.

Usar superfícies extremamente discretas de vidro escuro:

background rgba(255,255,255,0.02)

blur cinematográfico

borda quase invisível

reflexo azul extremamente sutil

sombra profunda

brilho apenas quando o cursor passar

Os elementos devem parecer objetos flutuando dentro de um ambiente escuro, não caixas em uma página.

CONTRASTE

Textos principais em branco quase puro:

#F5F5F5

Textos secundários em:

#8A8A8A

Nunca utilizar branco puro em excesso.

Grandes áreas devem permanecer vazias e escuras para criar sensação de luxo.

FRAME CINEMATOGRÁFICO

Durante a introdução, utilizar um frame cinematográfico widescreen.

A tela começa quase totalmente preta.

Uma pequena faixa de luz azul aparece.

A câmera começa a revelar a cena.

O frame se abre lentamente.

A imagem do Andrey aparece.

O preto ocupa grande parte da tela.

A luz recorta o personagem.

O nome:

ANDREY

surge lentamente.

Depois:

FUNDADOR DA TEC RN

Pequeno, elegante e espaçado.

Nada de animações rápidas.

Tudo deve parecer caro, controlado e intencional.

ATMOSFERA

A sensação geral deve ser:

luxo tecnológico + cinema + mistério + ambição + futuro.

Imagine:

uma sala completamente escura,

um notebook iluminando o rosto,

luzes azuis refletindo no ambiente,

uma cidade distante,

partículas no ar,

e uma câmera cinematográfica se aproximando lentamente.

O site deve parecer uma experiência digital premium, e não uma landing page feita por inteligência artificial.

REGRA PRINCIPAL

Menos elementos.

Mais espaço.

Mais contraste.

Mais profundidade.

Mais luz.

Mais preto.

O usuário deve sentir que está entrando em um filme sobre a ascensão de Andrey e da TEC RN.
